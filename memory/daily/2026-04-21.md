## 今日学习内容

### D1 学习总结：类型注解 + Pydantic + f-string

**① 类型注解（Type Hints）**
- Python 类型注解是"渐进式"的——3.5+ 引入，不强制执行，仅供 IDE 和 mypy 使用
- 与 Java/TS 的本质差异：注解不强制，Java 的类型是编译期铁腕，Python 全靠自觉 + mypy/Pydantic 补位

**② Pydantic 数据模型**
- 解决"类型注解不强制"的痛点——在**运行时**做校验，不合法数据直接抛 `ValidationError`
- 对比 Java 的 Bean Validation：JSR-380 用注解（`@NotNull`、`@Min`），运行时反射校验；Pydantic 用 Field() + 验证器，更直观

**③ f-string 格式化**
- Python 3.6+ 字符串插值，语法 `f"hello {name}"`
- 比 JS 模板字符串和 Java `String.format()` 更简洁，可读性最好
