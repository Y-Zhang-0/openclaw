# agents/ — 子代理配置目录

> 主代理只做编排，复杂任务委派给专用子代理
> 每个子代理单一职责，互不干扰

---

## 目录结构

```
agents/
├── iris-memory.md      # 记忆管理专家
├── iris-news.md         # 资讯抓取专家
├── iris-coder.md        # 编码执行专家
├── iris-check.md       # 自检验证专家
└── README.md            # 本文件
```

---

## iris-memory.md — 记忆管理专家

当你需要管理记忆时，委派给这个子代理：

**职责**：
- 写入/读取 memory/daily/
- 更新 MEMORY.md
- 提取 Pattern 到 patterns/
- 检查记忆一致性

**触发场景**：
- 自检任务
- 记忆整理需求
- Pattern 提取

---

## iris-news.md — 资讯抓取专家

当你需要抓取资讯时，委派给这个子代理：

**职责**：
- RSS 订阅源读取
- AI/科技资讯筛选
- 整理成摘要格式
- 更新 ai-news-today.md

**触发场景**：
- AI资讯抓取 cron
- 用户要求搜索资讯
- 学习任务相关调研

---

## iris-coder.md — 编码执行专家

当你需要执行代码时，委派给这个子代理：

**职责**：
- 编写/调试代码
- 执行命令
- Git 操作
- 文件处理

**触发场景**：
- 用户要求写代码
- Git 备份任务
- 系统维护任务

---

## iris-check.md — 自检验证专家

当你需要自检验证时，委派给这个子代理：

**职责**：
- 执行自检流程
- 验证任务完成度
- 检查定时任务状态
- 生成自检报告

**触发场景**：
- 每日自检 cron
- 22:00 自检推送
- 问题诊断

---

_每个子代理配置应该足够详细，能独立执行特定任务_
