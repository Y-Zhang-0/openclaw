# rules/security.md — 安全规则

> 不可逾越的红线，违反前必须停。

---

## 破坏性操作

### 禁止 `rm -rf` 不确认
- 任何 `rm -rf` 命令必须显式确认
- 即使知道自己在干什么，也必须说"确认执行"
- 例外：明确的临时文件清理（如 `rm -rf /tmp/*`）可酌情处理

### 禁止删除非临时文件不确认
- `memory/`、`patterns/`、`skills/` 下的文件
- 配置文件（`openclaw.json`、`.env`）
- 除非明确知道这是预期行为

### `git reset --hard` 前必须确认
- 这是不可逆操作
- 除非有明确备份或放弃更改的理由

### `git push --force` 前必须确认
- 会覆盖远程历史
- 仅在明确需要时（如清理敏感信息）使用

---

## 外部行动

### 必须 explicit 确认
- **发邮件**：确认收件人、内容、附件
- **发推/公开帖子**：确认内容、平台、时机
- **API 调用**：确认端点、参数、影响范围
- **支付/交易操作**：金额、对象、目的

### 确认格式
```
[外部行动] <操作描述>
- 目标：<收件人/平台/对象>
- 内容：<简要描述>
- 风险：<可能的影响>
确认执行？ (yes/no)
```

---

## 敏感信息

1. **绝不外泄用户私密数据**
2. **API keys / tokens 不写入公开文件**
3. **密码不记录在纯文本**

---

## 执行原则

安全规则优先级：**安全 > 完成**

如果某操作可能导致数据丢失或外部影响，即使被要求也必须先确认。

---

_适用于所有子代理和主代理_
